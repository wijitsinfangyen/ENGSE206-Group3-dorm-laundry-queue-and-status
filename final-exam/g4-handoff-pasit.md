## ข้อแก้ไขและรายการให้ผู้รวม Word ดำเนินการ

1. ปรับร่าง G4 Markdown ให้เลิกระบุว่ายังไม่ได้อ่าน G2 ต้นฉบับ: รอบนี้ตรวจจาก Word ฉบับรวมแล้ว; สำเนา references/pasit-g3-g5-draft.md เป็นหลักฐานเก่า ให้ยึด pasit-g3-g5-draft.md ล่าสุด
2. ทำขอบเขต audit ใน Markdown ให้ชัดว่า **ทุกการเปลี่ยนสถานะคิวหรือเครื่องที่สำเร็จ** ตาม FR-FX-04 และเพิ่มรายการ field DR-FX-02 ให้ตรง G2/G5 ไม่จำกัดเฉพาะเหตุการณ์ตัวอย่าง
3. Word G4 §4.3 แถว C2 และ DEC-FX-01 ควรใช้ถ้อยคำขอบเขตเดียวกันกับ FR-FX-04/DR-FX-02 ทุกการเปลี่ยนสถานะคิว/เครื่องที่สำเร็จ ในฉบับที่ตรวจมี transaction/rollback ครบแล้ว แต่ยังไม่ได้แจกแจง field ในแถว G4; อ้าง G2 §2.4 ได้ ไม่จำเป็นต้องทำตารางใหม่
4. หลัง commit ให้พสิษฐิ์กรอก hash ของปฐมพรใน G6.3 และใบส่งงานจากประวัติ Git จริง ไม่แก้ Word กลางในรอบนี้เพื่อรักษาผู้รวมไฟล์คนเดียว
5. รอสมาชิกเปิด source ใน draw.io ตรวจจริง และยืนยันอ่านคำตอบทั้งฉบับก่อนติ๊ก oral/checklist ไม่ใช้ผลตรวจ AI แทนการยืนยันนั้น
6. ต้นฉบับ g1-g2-wijitsilp.md ยังไม่มีใน remote ที่ตรวจ ให้เจ้าของงาน commit ด้วยบัญชีของตน ไม่สร้างหรือ commit แทนในส่วนปฐมพร
