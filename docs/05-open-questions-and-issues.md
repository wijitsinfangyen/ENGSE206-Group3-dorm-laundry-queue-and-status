## 2. Issues / Holds

| Issue ID | เรื่องที่ต้อง Hold | เหตุผล | สิ่งที่ต้องเก็บเพิ่ม |
|---|---|---|---|
| **ISSUE-DLQS-01** | กำหนดเวลา No-show Timeout ที่เป็นธรรม | ยังไม่มีข้อสรุปตัวเลขที่ลงตัวระหว่างการไม่ให้คิวสะสมกับการเผื่อเวลาเดินลงมาจากห้องพัก | ผลสำรวจความคิดเห็นนักศึกษา + นโยบายยินยอมจากผู้ดูแลหอพัก |
| **ISSUE-DLQS-02** | สิทธิ์การกดปิดสถานะ "เครื่องเสีย" | ยังไม่ยืนยันว่านักศึกษาสามารถกดแจ้งเสียแล้วระบบปิดรับคิวทันทีได้เลย หรือต้องรอ Dorm Admin อนุมัติก่อน | Workflow การรับแจ้งปัญหาจริง + นโยบายการป้องกันการกลั่นแกล้งกดปิดเครื่อง |
| **ISSUE-DLQS-03** | ระเบียบปฏิบัติ (SOP) การจัดการผ้าค้างเครื่อง | ยังไม่มีข้อตกลงเรื่องพื้นที่กลางสำหรับวางผ้า และความยินยอมเรื่องความปลอดภัยของทรัพย์สิน | กฎระเบียบหอพักเรื่องผ้าค้างเครื่อง + การลงนามรับทราบของนักศึกษา |
| **ISSUE-DLQS-04** | รูปแบบการตรวจจับสถานะเครื่อง (Sensor vs Timer Simulation) | ยังไม่มีงบประมาณและข้อสรุปทางเทคนิคร่วมกับฝ่ายไอทีเกี่ยวกับการติดตั้งอุปกรณ์ IoT | ข้อจำกัดทางโครงสร้างเครื่องซักผ้า + งบประมาณปรับปรุงอุปกรณ์ |
| **ISSUE-DLQS-05** | ช่องทางการส่ง Push Notification | ยังไม่ได้ข้อสรุปว่าจะใช้ Web Push API หรือ LINE Notify API เป็นหลักเพื่อไม่ให้มีค่าใช้จ่ายส่วนเกิน | ข้อจำกัดทางเทคโนโลยีและต้นทุน API (Messaging Cost) |
