# ชุดงานส่วน ก กลุ่ม 03

เปิด `final-exam-group-answer.docx` เพื่อตรวจ G1–G6 ฉบับรวม ภาพอยู่ใน `diagrams/` และไฟล์ร่างของแต่ละคนอยู่ในโฟลเดอร์นี้เพื่อให้ตรวจย้อนกลับได้

ไฟล์คำตอบจัดทำจากแบบฟอร์มอาจารย์ คงหน้ากระดาษ/ส่วนหัว/ท้าย/รูปแบบตารางต้นฉบับ และแก้ความกว้างตารางที่เกินขอบเมื่อกรอกข้อความ

## ก่อนส่งจริง

1. ให้ทุกคนอ่าน Word ฉบับรวม และเปิด source Draw.io ตรวจทั้งสองภาพ
2. ให้แต่ละคน commit งานของตนใน branch `final-exam` ด้วยบัญชีตนเอง
3. กรอกหลักฐาน commit จริงในใบส่งงาน แล้ว push และเปิด PR เข้า `main` ชื่อ `submit(final): change-to-design take-home` ไม่ merge เอง
4. เติม URL PR และ hash ของ commit ชุดส่งจริง อย่านำ hash ของ SRS ฐานมาแทน
