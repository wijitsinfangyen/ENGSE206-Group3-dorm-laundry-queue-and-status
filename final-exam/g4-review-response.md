| ข้อ review | สิ่งที่แก้ในรอบนี้ | หลักฐาน / ข้อจำกัด |
|---|---|---|
| 1 Source ภาพใน ZIP ไม่ครบ | รวม context-after.drawio และ container-after.drawio พร้อม PNG, ข้อมูลรูปทรงและสคริปต์ใน ZIP รอบใหม่ | ตรวจรายการและอ่านไฟล์ใน ZIP; ไม่อ้างว่าผู้รับเปิดใน draw.io แล้ว |
| 2 ฐาน G2 ยังไม่ทันฉบับแก้ | เพิ่ม FR-FX-03/04, DR-FX-02, BR-FX-02 เป็น Proposed ตามข้อมูลในผล review | ยังต้องเทียบต้นฉบับ G2 ฉบับแก้ไข; ไม่อ้างว่าได้รับต้นฉบับจากเพียงบันทึก review |
| 3 รายการแจ้งในเว็บ | อัปเดต §4.1–4.6 และ DD-FX-01/05 ให้สร้างฝั่ง server ได้แม้เว็บปิด เจ้าของอ่านย้อนหลังได้แม้ไม่ opt-in ภายนอก | FR-FX-03, US-FX-02, UC-FX-02, AC-FX-06; ไม่ใช่ browser push |
| 4 รหัส audit ซ้ำ | เลิกใช้รหัสเสนอ audit เดิมของ G4 ใช้ FR-FX-04/DR-FX-02/BR-FX-02 และ US-FX-03/UC-FX-03/AC-FX-07–09 | ปรับตาราง container, Decision cards, Spine และ DD-FX-05 |
| 5 audit ล้มเหลว | ระบุ transaction สถานะ+audit เดียวกัน ถ้า audit ล้มเหลว rollback สถานะเดิม ไม่ยืนยันหรือแจ้งว่าสถานะใหม่สำเร็จ | AC-FX-08; เพิ่มข้อความใน C2/C3 และลูกศร transaction ในภาพ Container; ยังไม่ได้ทดสอบระบบจริง |
| 6 อ่าน audit | เพิ่มหน้าที่ Web App/ผู้ดูแลและเส้นทางอ่านผ่าน C2 ตรวจ BR-FX-02; ปฏิเสธนักศึกษาอ่าน/แก้ลบผ่านงานทั่วไป | UC-FX-03/AC-FX-09; อ่านแบบง่าย Build now; รายงาน/ค้นหาขั้นสูง Later |
| 7 checklist | แยกการมีไฟล์ใน workspace/ZIP ออกจากการได้รับและเปิดตรวจ source ของผู้รับ; คงการอ่าน/รับรองของสมาชิกเป็นช่องรอ | ไม่มีการติ๊กการอ่านของปฐมพรหรือสมาชิกแทน; รอเทียบ ID และภาพร่วมกัน |
