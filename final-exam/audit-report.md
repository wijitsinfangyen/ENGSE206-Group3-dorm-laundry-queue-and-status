## ตรวจความสอดคล้องข้ามส่วน

- SRS ฐาน commit `b46b207cb148c2730f1f3b68af9989b11f9d12f1` ยังตรงกับ main ของ repo กลุ่ม ณ วันที่ตรวจ สถานะใน SRS คือ Baseline Candidate
- W08 เดิมมีข้อความ Approved & Locked แต่ชุดสอบไม่ใช้เป็นหลักฐานอนุมัติ CR/SRS ใหม่ และไม่แก้ไฟล์เดิม
- ค่าเตือนก่อนซักเสร็จ 5 นาทีและ no-show 10 นาทีมาจาก FR-04 และ FR-03/BR-02; ค่าเวลาใหม่เป็น TBD/OI-FX-02/DD-FX-02

- BR-FX-02 อนุญาตผู้ดูแลที่มีสิทธิ์อ่าน audit แบบง่าย ปฏิเสธนักศึกษาอ่านและการแก้/ลบผ่านงานทั่วไป; รายงาน/ค้นหาขั้นสูง Later

- การส่งภายนอกล้มเหลวไม่ย้อนคิวหรือยืด grace period; retry/restart/กันซ้ำ/retention ที่ยังไม่ตกลงเป็น DD ไม่อ้าง exactly-once หรือผลทดสอบที่ไม่มี
- FR-06 เป็น Overview และ FR-07 เป็น Later ตามข้อเสนอ 02B; ไม่ลบออกจาก SRS และต้องให้เจ้าของระบบยอมรับข้อจำกัด

## ตรวจไฟล์และรูปแบบ

- ไฟล์บังคับ 7 รายการครบ: Word 1, Draw.io 2, PNG 2, ใบส่งงาน 1, AI log 1
- Word เปิดได้ด้วย Microsoft Word 16.0 และแสดงผล 21 หน้า ไม่มีหน้าว่าง ไม่พบข้อความ/ตารางล้นขอบหลังแก้ไข รูปภาพทั้งสองฝังอยู่ในไฟล์ ไม่ได้ลิงก์ไปยังไฟล์ชั่วคราว
- คง 4 sections และหน้ากระดาษแนวตั้ง/แนวนอนตามแบบฟอร์ม; คง source styles/numbering/header/footer และส่วน ZIP เดิมที่ไม่แก้ 35 รายการแบบ byte-identical
- ตรวจชื่อ–รหัสตามข้อมูลผู้ใช้ครบ: นายวิจิตรศิลป์ ฟังเย็น 68543210068-1; นายพสิษฐิ์ เพชรอำพันธุ์ 68543210036-8; นายปฐมพร หลีจาง 68543210034-3
- ตรวจ reference ID ใหม่แบบ FX 29 ID ใน Word พบในร่าง G2 ฉบับแก้ไข ไม่พบ template ชื่อระบบ/รหัสสมาชิกที่ยังว่าง, conflict marker หรือ citation token จากเครื่องมือ
- Draw.io XML ทั้งสอง parse ได้: Context 4 เส้น, Container 7 เส้น ไม่พบ source/target อ้างกล่องที่ไม่มีอยู่ ป้ายลูกศรเป็น text cells แยกและตรวจเห็นใน PNG แล้ว
- ภาพกับ source มาจากชุด G4 รอบที่ตรวจแล้ว; ไฟล์ 19 รายการตรง manifest รอบก่อน ชุด G4 ZIP ล่าสุดเปลี่ยนเฉพาะ AI log และ manifest
- การตรวจ XML/PNG ยังไม่ใช่การเปิด source ในแอป draw.io และไม่ใช่ผลทดสอบระบบซอฟต์แวร์จริง
